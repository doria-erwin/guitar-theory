Guitar Theory Explorer

Scales, chords, keys and rhythm, worked out on the fretboard. Runs offline.

The interactive app needs JavaScript

If you can read this, scripts have not run. Some file previews (for example inside chat or mail apps on iPhone) display HTML without running JavaScript, and there is no way for a page to override that.

To use the app: save the file and open it in Safari, Chrome, Firefox or Edge. On iPhone: share the file to the Files app, then open it from Files, or use “Open in Safari”. On a computer, double-click the file.
